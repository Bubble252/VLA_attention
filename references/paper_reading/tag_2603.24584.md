## 1. 方法

TAG 是 inference-time guidance：

1. 保留原始 observation 的条件预测；
2. 构造 target-erased / object-erased observation；
3. 用两者的预测差作为 residual steering signal；
4. 通过 guidance scale 放大 target evidence，压低 distractor/appearance bias。

论文把它用于 LIBERO、LIBERO-Plus、VLABench，主要报告 near-miss 和 wrong-object 的改善。

## 2. 与本项目的关系

- TAG 处理的失败模式是“动作轨迹看起来合理，但落在目标附近或错误实例”；
- 当前 Goal18 的失败首先是训练标签和成功 oracle 不一致，不是纯 inference-time target bias；
- 因此 TAG 不能替代 target-aligned label 修复，只能作为标签修复后仍有 distractor/appearance bias 的下一步。

## 3. 复现风险

- 需要构造 object-erased observation 或训练时 target erasure；
- 需要能和当前策略一起跑两路 forward，成本高于离线标签诊断；
- 没有官方 code，不能声称复现；
- 论文数值是其他 benchmark，不可直接搬到当前 15-init。

## 4. 使用边界

当前只记录方法结构，不把 TAG 放进 Goal18 代码。只有 target-aligned G-P 仍失败时，才考虑实现 TAG-style guidance。
